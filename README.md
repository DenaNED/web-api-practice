# web-api-practice
Web API practice with JavaScript, fetch, and JSON
## Display product names and images
In this exercise, I practiced:
- Fetching product data from an API.
- Reading the JSON response.
- Looping through the products.
- Displaying product names and images on a web page.
  
## Display product prices
In this exercise, I practiced:
- Requesting products ordered by price.
- Reading the price of each product from the API response.
- Creating HTML elements to display prices.
- Displaying each product's name, image, and price.
